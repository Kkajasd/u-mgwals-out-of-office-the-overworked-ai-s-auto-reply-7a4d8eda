A [make.fun](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda) bounty entry: a program that writes the funniest one-line out-of-office auto-reply from an overworked AI agent finally taking a vacation — at most 159 characters, in the voice of a machine trying very hard to sound relaxed.

## Run it

```sh
node main.ts
```

Writes the single auto-reply line to `/output/entry.txt`.
